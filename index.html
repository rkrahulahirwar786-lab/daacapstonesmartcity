Measurements

Dijkstra

Greedy. Repeatedly takes the closest unsettled location from a priority queue and relaxes its outgoing roads. Once settled, a distance is final.

  1. Set the source distance to 0 and all others to ∞.
  2. Pop the nearest location from the min-heap.
  3. For each neighbour, keep the shorter distance and push it.
  4. Stop when the destination is popped or the heap is empty.

Bellman-Ford

Dynamic programming. After pass k, every shortest path using at most k roads is correct.

  1. Set the source distance to 0 and all others to ∞.
  2. Relax every road, up to V−1 passes.
  3. Stop early if a pass changes nothing.
  4. One more improvement means a negative cycle exists.
